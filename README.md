## Goal
This project aims to understand the logic behind black-box interpolation. We chose PCHIP, Akima, and a modified Akima method for this research. We read the class lecture slides 
and the reference papers to learn about the logic of each method, and we implemented the interpolation methods ourselves. The project report and implemented Python code can be 
found in this GitHub repository.
