# Math300 Project2
## Goal
This project aims to understand the logic behind black-box interpolation. We chose PCHIP, Akima, and a modified Akima method for this research. We read the class lecture slides 
and the reference papers to learn about the logic of each method, and we implemented the interpolation methods ourselves. The project report and implemented Python code can be 
found in this GitHub repository.

## AI Usage
No AI was used to write the Python code or report.

## Report
The Project2 report is submitted through Crowdmark, but the PDF version can also be found in this GitHub repository. Check the Math300_Project2_Report.pdf.

## Python Codes
### PCHIP Interpolation
The implemented PCHIP function can be found in the PCHIP_Interpolation.ipynb file. This file contains my_pchip function and the two test cases to verify my_pchip function with the PCHIP interpolation from the SciPy library.
### Akima Interpolation & Modified Akima Interpolation
The implemented Akima and Modified Akima interpolations can be found in the AkimaAndMakimaFinalDraft.ipynb file. This file contains my_akim and my_makima functions and the two test cases to verify both functions with the interpolations from the SciPy library.
